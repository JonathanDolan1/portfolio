overview: Igor is a Telegram assistant that runs on an old Lenovo laptop I turned into a home server (Xubuntu). AI coding agents (Claude Code, Codex) wrote most of the code; I set the requirements, review the changes, and direct and approve its deployments and fixes.
problem: I juggle shift work, a job search and several side projects, and things were slipping between apps and notes. I wanted one always-on assistant I could message for reminders, tasks and a daily overview, and one that would stay reliable and cheap to run without me watching it.
solution: An owner-only Telegram chat backed by memory, tasks and reminders, a daily morning brief and status reporting. It runs as a systemd service, sends a heartbeat to an outside monitor, and enforces a monthly spend cap on AI usage. A plain-language runbook covers common failures.
stack:
  - Python
  - Telegram Bot API (python-telegram-bot)
  - Claude API (Anthropic SDK)
  - SQLite
  - systemd on Xubuntu
  - healthchecks.io heartbeat monitoring
learnings: "Running Igor taught me the operations side of software. A service is only useful if you can tell when it stops, so it reports a heartbeat and its own status. Costs need a real limit, not good intentions: Igor stops starting new conversations once the monthly cap is reached. A runbook written in plain language turns a 2 a.m. failure into a checklist. Directing AI agents also taught me to review changes, ask for tests, and approve deployments only when I understand what changed."
